# My Portfolio

A personal portfolio website built with React and TailwindCSS.

## Live Demo

[Visit Portfolio](https://your-netlify-url.netlify.app)

## Tech Stack

- React 18
- TailwindCSS 3
- Framer Motion
- React Router v6
- React Icons

## Features

- Responsive design
- Dark/Light theme toggle
- Animated page transitions
- Project showcase with live links
- Contact form
- Downloadable CV

## Projects

- **Invoixa** - Invoice Application ([Live](https://invoixa.netlify.app))
- **Roof Toppers** - Roofing Website ([Live](https://rooftoppers.netlify.app))
- **Weather App** - Weather Application ([Live](https://boileenweather.netlify.app))

## Getting Started

```bash
npm install
npm start
```
